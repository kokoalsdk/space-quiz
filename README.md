# 우주 탐험 퀴즈

태양계와 우주에 관한 10문제를 풀어 보는 한국어 퀴즈 앱입니다. 문제마다 정답 여부와 해설을 보여 주고, 마지막에 점수에 따른 결과를 알려 줍니다.

HTML, CSS, JavaScript가 `index.html` 한 파일에 들어 있으며 외부 라이브러리나 서버 없이 동작합니다.

## 로컬 실행

빌드나 설치 없이 `index.html`을 브라우저에서 열면 됩니다(`file://`).

## 배포

`main` 브랜치에 푸시하면 GitHub Actions(`.github/workflows/pages.yml`)가 GitHub Pages에 자동 배포합니다.
